# Myntra Homepage Clone

A frontend clone of the Myntra homepage built using **HTML and CSS**. This project recreates the basic layout and visual design of Myntra's website, focusing on styling, positioning, navigation, and responsive design elements.

### 🛠️ Technologies Used
- HTML5
- CSS3

### 🎯 Purpose
Built as a beginner-friendly web development practice project to strengthen my understanding of HTML structure, CSS styling, layouts, and frontend development.

### 📌 Note
This is a practice project and is not affiliated with or endorsed by Myntra.
